# DPA4-Neo foundation

Run `python prepare_model.py` from the example directory to download
`DPA4-Neo-OMat24-v20260805.pt` from the official
[DPA4-OMat24 release](https://huggingface.co/deepmodelingcommunity/DPA4-OMat24).
The downloader pins revision `173bfd5a26f90a756ee891777270ef117078d9be`.
An existing copy of this exact checkpoint can also be placed in this directory.
