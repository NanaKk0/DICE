# Changelog

## 0.2.0 — 2026-11-18

- Added native sampling inheritance and explicit overrides with automatic input assembly.
- Added a portable DICE Operator skill for compatible coding agents.
- Reorganized the English documentation into tutorials, guides, concepts, references and development.
- Added a ready-to-run DPA4/DPA4C water example with configurations and
  reference data for iter0 and iter1.
- Added installation, input preparation, backend setup, sampling, resources
  and recovery guidance.
- Documented screening policies, configuration fields and data formats.
- Added documentation rendering and local link checks.

## 2026-11-11: DeepMD integration

[PR #1](https://github.com/NanaKk0/DICE/pull/1) added support for native
DPA4/DPA4C presets, analytical ZBL model composition, foundation element maps,
atomic-feature readout and automatic neighbour graphs.

## 2026-11-02/03: initial public distribution

- Published the iter/round workflow, command-line interface and backend
  adapters.
- Added workflow tests, documentation and licensing information.
