# Paper and research resources

| Goal | Resource |
| --- | --- |
| Install and learn DICE | This repository; CPU mock and FP handoff examples |
| Verify paper numbers or export figures/tables | [DICE-paper](https://github.com/NanaKk0/DICE-paper): code and numerical source data together |
| Use the study's trained models | DICE-models.zip + DICE-datasets.zip; see the paper MODEL_USE.md |
| Read labelled training/reference/test configurations | DICE-datasets.zip |
| Inspect raw outputs and repeat-level evidence | DICE-extended-evidence.zip |

Pretrained DPA4/DPA4C weights must be obtained from their official projects.
Install native engines separately and connect them through environment profiles.

The dataset archive contains labelled extxyz, including the historical cross-phase
student datasets and liquid-amorphous test120. The paper repository provides
the numerical analyses and per-figure commands for these research assets.

Use the [native environment guide](native-models.md) to prepare scientific
execution, or the CPU mock to explore the workflow. Research-asset downloads and
the archive DOI will be linked here when the Zenodo record is published.
